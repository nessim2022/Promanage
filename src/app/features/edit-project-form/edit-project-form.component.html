Modifier le projet
Le nom du projet est requis. Le nom du projet doit contenir au moins 3 caractères.
La description est requise.
L'URL GitLab est requise. L'URL GitLab doit être au format https://gitlab.com/...
La date de début est requise.
La date de fin est requise. La date de fin doit être postérieure à la date de début.
